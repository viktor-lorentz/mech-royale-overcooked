# mech-royale-overcooked

Team Overcooked bot for the Builders Buildathon Mech Royale track (protocol mechfight/1).
Rust bot at repo root (Dockerfile at top level). `kit/` is the official starter kit for reference.

Local check: `cargo build --release && python3 kit/check/check.py --map-dir "$PWD/kit/arena" -- ./target/release/mech-bot`
